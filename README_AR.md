# محلل كرة القدم لـ Claude (MCP)

إضافة محلية لـ **Claude Desktop** تعرض مباريات كرة القدم حسب التاريخ، ثم تحلل مباريات مختارة باستخدام بيانات API-Football.

## المزايا

- `list_matches`: عرض المباريات في يوم معين، مع فلاتر الدوري والدولة والفريق والحالة. الافتراضي هو توقيت القاهرة.
- `analyze_match`: تحليل مباراة محددة بالمعرّف `fixture_id`.
- `analyze_today_matches`: يجلب جدول اليوم ثم يحلل عددًا محدودًا من المباريات لتوفير رصيد API.
- احتمالات الفوز/التعادل/الخسارة، الأهداف المتوقعة، احتمالات Over/Under، تسجيل الفريقين، والنتيجة الأكثر احتمالًا عبر نموذج بواسون مبسط.
- تحليل آخر النتائج، الإصابات/الغيابات، المواجهات المباشرة، ومتوسطات الركنيات والتسديدات داخل منطقة الجزاء عندما تتوفر الإحصائيات.
- تخزين مؤقت للطلبات لتقليل استهلاك حصة API.

## ما الذي تحتاجه؟

1. **Claude Desktop** على Windows أو macOS أو Linux. ملفات MCPB تُثبت من واجهة Claude Desktop، وليس من تطبيق Claude على الهاتف أو موقع Claude في المتصفح.
2. مفتاح API من [API-Football](https://www.api-football.com/).
3. إصدار حديث من Claude Desktop يدعم MCP Bundles (MCPB) وبيئة UV.

## التثبيت في Claude Desktop

1. أنشئ حسابًا في API-Football وخذ قيمة API Key من لوحة التحكم. لا تشارك المفتاح في المحادثة ولا تضعه في ملف عام.
2. افتح Claude Desktop.
3. اذهب إلى **Settings → Desktop app → Manage** بجوار Extensions.
4. افتح **Advanced settings → Extension Developer → Install Extension…**.
5. اختر ملف `football-analyst.mcpb`.
6. عند ظهور إعدادات الإضافة، ضع مفتاح API-Football في خانة API Key، واترك المنطقة الزمنية `Africa/Cairo`.
7. أكمل التثبيت ثم أعد تشغيل Claude Desktop عند الحاجة.
8. من زر **+ → Connectors** تحقق من ظهور Football Analyst وأدواته.

> إذا لم يقبل إصدار Claude لديك ملف MCPB، استخدم التشغيل اليدوي الموضح أدناه. يلزم تثبيت Python 3.10+ وUV في هذه الحالة.

## أمثلة أسئلة إلى Claude

- «هات كل مباريات كرة القدم النهارده بتوقيت القاهرة، مرتبة حسب موعد البداية».
- «اعرض مباريات الدوري الإنجليزي اليوم فقط».
- «حلل المباراة ذات المعرّف 1234567 تحليلًا كاملًا».
- «حلل أفضل 5 مباريات اليوم، ووضح احتمالات 1X2 والأهداف والركنيات والتسديدات داخل المنطقة».
- «قارن توقعك المستقل بتوقع API-Football، وقل لي أين يوجد تعارض».

## التشغيل اليدوي (بديل)

من مجلد المشروع:

```bash
# Windows PowerShell
py -3.10 -m venv .venv
.venv\Scripts\Activate.ps1
pip install -e .
$env:API_FOOTBALL_KEY="ضع_مفتاحك_هنا"
$env:FOOTBALL_TIMEZONE="Africa/Cairo"
python server.py
```

هذا يشغل خادم MCP على STDIO. لإضافته يدويًا إلى Claude Desktop، استخدم إعداد خادم محلي في إعدادات المطور، واجعل `command` هو مسار Python داخل `.venv` و`args` هو المسار الكامل إلى `server.py`، ومرر `API_FOOTBALL_KEY` و`FOOTBALL_TIMEZONE` في `env`.

## ملاحظات مهمة عن الدقة والتغطية

- مباريات اليوم تعني كل المباريات التي يعيدها API-Football للموعد المحدد، وليست وعدًا بتغطية كل دوري أو منتخب في العالم. راجع تغطية البطولة داخل حساب المزود.
- الباقة المجانية المنشورة حاليًا محدودة بـ100 طلب يوميًا. تحليل المباراة الواحدة يستهلك عدة طلبات، ولذلك يحدد `analyze_today_matches` التحليل العميق افتراضيًا بخمس مباريات، وبحد أقصى ثماني مباريات في الاستدعاء. قد تحتاج باقة أعلى إذا حللت مباريات كثيرة يوميًا.
- بيانات التسديدات داخل المنطقة والركنيات متاحة عادةً بعد بدء المباراة أو اكتمالها. تقدير ما قبل المباراة في هذه الإضافة هو متوسط مرجّح من إحصاءات آخر المباريات المتاحة، ويُعرض معه حجم العينة. إذا لم تتوفر عينة كافية فستظهر `null` بدل اختلاق رقم.
- التوقعات الإحصائية ليست ضمانًا للنتيجة ولا نصيحة مالية. كرة القدم عشوائية، والتشكيلات والغيابات قد تتغير قرب موعد المباراة.
- قد تكون بيانات الغيابات أو التشكيلات غير متاحة لبعض البطولات أو قبل وقت كافٍ من المباراة. شروط API-Sports تنص على أن إعادة بيع البيانات غير مسموحة، وأن الاستخدام ضمن منصات مراهنات أو بث أو توزيع جماهيري قد يتطلب تراخيص إضافية؛ راجع الشروط قبل أي استخدام تجاري أو إعادة توزيع.
